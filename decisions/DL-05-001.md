# DL-05-001: HTTP katmanı — `node:http` + Express-uyumlu middleware zinciri

- Tarih: 2026-08-10
- Faz: 5 — Mimari Tasarım
- Mod: AUTOPILOT
- Karar: HTTP katmanı Node stdlib'inin `node:http` modülüyle kurulur; üstüne Express'in `(req, res, next)` imzasıyla **birebir uyumlu** ince bir middleware zinciri (`logger → securityHeaders → accessGate → jsonBody → router → errorHandler`) ve basit bir method+path router'ı (`src/router.js`) yazılır. Tüm uygulama route'ları `server.js`'te tek bir `MOUNT_PREFIX` altına bağlanır ve `accessGate` router'dan ÖNCE çalışır (`/health` muaf) — NFR-3'ün Faz 7'de doldurulacak kancası budur.
- Değerlendirilen alternatifler: (1) **Express 5** — olgun router/middleware, hazır statik dosya servisi, npm bağımlılığı + `npm install` gerektirir; (2) `node:http` üzerine elde yazılmış zincir (seçilen); (3) framework'süz tek `if/else` handler — middleware kancası ve dolayısıyla NFR-3 için tek giriş noktası olmazdı, elendi.
- Gerekçe: Faz 4'ün taşıdığı sıfır-dış-bağımlılık kısıtı (better-sqlite3'ü eleyen aynı kısıt) ve fabrika Execution Policy'sinin Faz 9'da ağ erişimi vermemesi, geliştirme sırasında `npm install express` yapılamayacağı anlamına gelir. Ürün yüzeyi 6 route + 4 statik dosyadan ibaret olduğundan Express'in kazandırdığı router/statik servis ~60 satırla karşılanır; buna karşılık ~30 transitif paketlik tedarik zinciri yüzeyi (sağlık verisi tutan bir uygulamada A06 riski) ve ek build adımı eklenmez. Middleware imzası bilinçli olarak Express-uyumlu tutulur, böylece karar geri alınabilir kalır.
- Riskler: Elde yazılan router'da yol ayrıştırma/yönlendirme hatası (ör. path traversal ile statik dosya sızıntısı) — statik servis izin listesiyle sınırlanır (yalnız `index.html`, `app.js`, `styles.css`, `/js/derive.js`) ve Faz 7 checklist'inde denetlenir. Uzun vadede route sayısı büyürse elde yazılan router bakım yükü doğurabilir.
- Geri alınabilirlik: Yüksek (middleware imzası ve handler sözleşmesi Express ile aynı; `server.js`'te `http.createServer(chain)` yerine `express()` kurmak ~20 satırlık tek dosya değişikliğidir, route/handler modülleri aynen kalır)
